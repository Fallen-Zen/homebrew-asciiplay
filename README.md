# homebrew-asciiplay

Homebrew tap for [asciiplay](https://github.com/Fallen-Zen/asciiplay) — shape-matched
ASCII art from images and video, in colour, at full frame rate in the terminal.

```sh
brew install Fallen-Zen/asciiplay/asciiplay
```

ffmpeg is pulled in automatically; asciiplay shells out to it for decoding.

To try the development version:

```sh
brew install --HEAD Fallen-Zen/asciiplay/asciiplay
```
